# Версия 0.1.0 — 16 октября 2026

## Что сохранено

Рабочий MVP анализа отзывов Яндекс Карт, интерфейс с этапами и превью, сверка цитат, Markdown-экспорт, Dockerfile, Compose, тесты и инструкция запуска. Репозиторий: `HEXYEBA/hse_domaha`, ветка `main`, версия отмечается тегом `v0.1.0`.

## Проверено

- Windows: **150 passed**, compileall успешен.
- Реальный короткий запрос через локальный Codex CLI: модель `gpt-6.1-sol`, `ok: true`, 6,1 с.
- [GitHub Actions для кода и Compose](https://github.com/HEXYEBA/hse_domaha/actions/runs/38815238422): сборка Linux-образа успешна, **146 passed, 4 skipped**. Пропуски относятся к поведению занятых файлов Windows и проходят в Windows-проверке. Одно предупреждение pytest связано с отсутствием права создавать необязательный кэш в корне образа; на результат тестов и приложение не влияет.
- В контейнере: Chromium на виртуальном экране, Codex CLI 0.160.1, пользователь без прав root, запись в отдельные тома авторизации и отчётов, старт Compose и HTTP health endpoint — успешны.
- Свежий контейнер не содержит `CODEX_HOME/auth.json`. Сессия владельца не передавалась в сборку или CI. Реальный запрос модели внутри контейнера требует самостоятельного входа; без него не запускался.
- Перед первой отправкой проверены все 64 файла, типовые форматы секретов, имена приватных файлов и совпадения с тремя локальными токенами Codex. Совпадений не найдено; сами значения не выводились и не сохранялись в документации.

Первый диагностический workflow использовал прямой `docker run` и был остановлен после успешной проверки итогового способа запуска через Compose с `init: true`. Итоговый workflow использует команды Compose из README.
