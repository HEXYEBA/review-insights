## Исправленные причины

- Лимит модели 120 с был недостаточен: реальный ответ на 50 отзывов пришёл за 140,56 с. Теперь на ответ отводится 300 с; возможна одна исправляющая попытка.
- Windows могла удерживать worker.stderr после остановки worker. Очистка временной папки больше не заменяет результат или исходную ошибку сайта на PermissionError.
- Сборщик сохранял данные лишь после всей порции карточек. Теперь каждый готовый отзыв сразу попадает в snapshot; чтение учитывает общий deadline, пустые карточки пропускаются без долгого ожидания.
- Подпись DOM читается атомарно. Проверка цитат и исправление отчёта имеют отдельные статусы; готовый UI показывает имя модели и время.
- Проверка входа с собственным лимитом 10 с имеет отдельную ошибку. Ошибки модели сохраняют безопасную диагностику без сообщений, исходных строк, отзывов, prompt и авторизации.

## Оставшиеся границы

- До 200 собранных и до 50 анализируемых отзывов; ограничение времени может дать частичную выборку. Модель не знает внутренние показатели заведения и не устанавливает истинность отзывов.
- До 300 с на ответ, до двух ответов при исправлении плюс время сбора. Время ответа и квота зависят от сервиса.
- HTTP 200 в свежем тесте не гарантирует будущую доступность Яндекса. После 429 автоматических повторов нет; личный профиль и cookies не копировались, CAPTCHA не обходится.
- Docker отложен. Git-коммита нет: репозиторий без первого коммита и локальной identity, глобальный Git config не менялся.
