# Материалы для защиты

Структура шести слайдов и сценарий демонстрации; файл PowerPoint не создавался.

## 1. Задача

Отзывы объясняют, что хвалят и критикуют посетители, но вручную читать и сопоставлять их долго. Цель MVP — превратить доступные тексты в проверяемые наблюдения для владельца.

## 2. Результат

Ссылка на Яндекс Карты → до 200 доступных отзывов → анализ максимум 50 → темы, цитаты, действия и гипотезы → Markdown. Примеры: Кофемания на Кутузовском и МИЭМ ВШЭ в Строгино.

## 3. Архитектура

Python проверяет URL и собирает данные Playwright-worker. Codex CLI через вход ChatGPT передаёт отзывы модели gpt-6.1-sol. Модель интерпретирует текст; обычный код проверяет ID, точные цитаты, ссылки и учёт каждого выбранного отзыва. Покупка API-ключа не потребовалась.

## 4. Демонстрация

1. Открыть http://127.0.0.1:8502, выбрать организацию.
2. Для быстрого показа нажать «Проанализировать» при свежем готовом отчёте или «Открыть сохранённый отчёт». Назвать дату сбора.
3. Показать собранное/проанализированное количество, имя модели, время, одну тему и её цитаты.
4. Скачать Markdown.
5. Если есть несколько минут, отдельно нажать «Обновить с Яндекса»: это новый сбор и настоящий вызов модели, который уже проверен целиком. Не запускать его многократно при ограничении источника.

## 5. Как проверяли

- Полный свежий UI-путь Кофемании: 154 собрано → 50 проанализировано, 10 тем; 229 с анализа и 294 с всего сценария.
- Скачанный через UI файл побайтно совпал с проверенным Markdown.
- МИЭМ: реальный отчёт 119 → 50; открытие и скачивание сохранённого результата проверены.
- 150 тестов; отдельные регрессии тайм-аута модели, занятого файла Windows, блокирующего раскрытия, пустой карточки и вставки ссылки.
- Цитаты и ссылки проверяет программа. Ручной просмотр небольшой выборки не даёт процента общей точности.

## 6. Ограничения

Это выборка отзывов, а не внутренние показатели или мнение всех клиентов. До 300 с на ответ модели, возможна одна исправляющая попытка; Яндекс и квота ChatGPT остаются внешними условиями. Даты и счётчики видны. Dockerfile и Compose добавлены; результат проверки контейнера указан в GitHub Actions. Для реального анализа в контейнере нужен отдельный вход пользователя.

В свежей проверке через настоящий интерфейс он собрал 154 отзыва Кофемании, проанализировал 50 и подготовил 10 тем. Модель работала около четырёх минут с исправлением отчёта, весь сценарий занял около пяти минут. Код проверил цитаты и ссылки, а скачанный файл совпал с проверенным отчётом. Для быстрого показа можно открыть этот сохранённый результат с его фактической датой. Выводы отражают отзывы и требуют проверки владельцем».
